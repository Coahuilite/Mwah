`AGENTS.md` 是 AI 协作者稳定入口；`MEMORY.md` 承载本地运行协议，`LESSONS.md` 只保留活跃经验及当前复盘覆盖点。人类贡献者从 README 与贡献指南开始即可。

现行文档完整承接操作所需规则和事实，不要求读旧聊天、外部维护文件或归档。`docs/archive/` 仅暂存已退役资料供维护者手动删除；必要的行为合同、渠道证据和未尽责任不放在那里。归档尚未删除时仍受仓库隐私门约束，不进入运行包。
