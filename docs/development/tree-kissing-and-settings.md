## 测试包与身份

- 生成命令：`pwsh scripts/pack-dev.ps1 -Zip`。
- 完整目录：`dist/dev/Mwah/`；ZIP：同目录旁的 `Mwah-dev-v0.3.0-<commit>.zip`，顶层为 `Mwah/`。
- `version.txt` 记录产品版本、`build=dev` 和 commit；交付应使用提交后生成、不带 `-dirty` 的包。两份 DLL 的产品版本也携带源提交身份。
- `1.6/Defs`、`1.6/Languages` 是唯一编辑源，打包为 1.6／1.7 各生成完整副本。**不要把源码 checkout 或仅 1.7 DLL 当作安装包。**
- 整个包内只包含运行内容、两份 Mwah.dll 和包身份；不含 Source、脚本、PDB、引用程序集或工坊 ID 文件。复制到游戏、游戏运行与存档由维护者操作。

## 实机验收与反馈

分别用 **1.6** 和 **1.7.4990 rev1069** 运行完整测试包，记录包内 `version.txt` 身份、游戏 build、DLC／模组组合，以及以下实际结果。不要混用旧 DLL 或同时加载两个 Mwah 副本；保留现有安装和存档以便恢复。

1. **启动与入口**：Core-only 启动无 Def／类型错误；中英文本和设置入口正常。右键、导演台两槽／心形／快速点选、自主撮合分别能到达请求及表演。
2. **双人工作**：错峰到位、路径／预订失败、配对与墙／树交叉占用；表演后回程、长回程受击和新命令不被旧活动抢回；手动命令受冷却限制，仅 `noCooldowns` 豁免。
3. **非 Pawn 扩展**：先在无 Ideology 时亲墙、亲树；再启用 Ideology，分别关闭／开启树文化结果，使用不同信仰 Pawn 亲普通树及自己／他人／未连接 Gauranlen。检查文化关闭仍有基础亲树，树结果更新同一记忆槽且与墙独立，原生连接／修剪／仪式不变。无心情 Pawn 不增加心情。
4. **设置实际使用**：首页扩展管理、两页导航和独立滚动；实际 UI 比例不遮挡标题／控件，三单位可读。编辑后分别用 Enter、失焦、切页、收起和关闭提交；关闭／重开及重载后偏好保留，非法文本不覆盖规范值；总开关／扩展开关及全部恢复默认真正影响后续请求和结算。
5. **更新与存读档**：保留旧配置／记忆更新；表演／回程中存读档，检查活动身份、只结算一次、回程及新局静态状态。空天意表、记忆替换／旁白和范围档位沿活动任务验收。

反馈提供身份、触发步骤、预期／实际及脱敏错误摘要即可；不要提交完整私人日志、存档或本地路径到仓库。维护者验收项仍由[活动任务 4.2 至 4.7](../../openspec/changes/tree-kissing-and-settings/tasks.md)管理；实机失败后按受影响合同修复，不以离线构建代替结果。
