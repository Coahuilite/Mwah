## 使用与生效

在“参数与杂项”的心情强度旁切换 **压缩超常社交收益**。默认开启，旧配置缺少 `socialImpactCompression` 时也开启；关闭偏好会保存，“恢复全部默认值”重新开启。

- 开启：最终 SocialImpact 不高于 137% 时不变；超出部分按有界曲线压缩，额外空间为 13 个百分点，有效值趋近 150%。
- 关闭：使用原始 SocialImpact。之后再乘玩家心情倍率；启用的好感变化共用同一倍率。它不限制多条记忆的总和，也不截断玩家主动设置的倍率。
- 只影响双人吻；不改 Pawn 技能／属性，不改亲墙／亲树结果，不加 Harmony。
- 结算时读取已提交的设置。切换开关或加载存档不会重算旧记忆；与同搭档再次合法完成亲吻，才更新该搭档的配对记忆。

137% 是技能因子参照，不是包含所有装备等因素的原版总上限。压缩最终属性会统一处理原版装备与模组的超出部分。

## 旧记忆刷新接缝

旧候选将新 `moodPowerFactor` 写进临时记忆后直接交给原版。已核对的 1.7.4990 rev1069 中，普通 `Thought_Memory.TryMergeWithExistingMemory` 在满组时只更新旧实例年龄，新倍率不会转移；社交变体则不合并。这是旧值可能被继续续期的源码证据，并非一次游戏复现。

当前两种既有可存档记忆类在原版合并钩子中调用 `KissMoodReward.PreparePairMemoryReplacement`。原版先完成思想／社交目标准入并赋好归属；本模组只对拥有搭档的 `MWAH_Kissed`／`MWAH_KissedBond` 定向移除同搭档旧条目，然后让原版加入已配置完的候选实例。由此更新倍率、适用好感、年龄、时长和旁白，并合并旧重复槽及两种变体。其他搭档不被该清理主动移除；原版既有堆叠约束仍生效。墙／树等其他 Def 继续调用原版 base 合并路径。

保留全部已有类型、Def、设置键及旁白存档字段，无全档扫描、补丁或批量存档迁移。1.6 的公开虚方法／字段通过原生引用编译确认；原生行为与 1.7 一起仍由维护者实机确认。

## 实机验收与反馈

维护者分别使用 1.6 和 **1.7.4990 rev1069** 的完整测试包，记录包身份、游戏 build 及实际输入／结果；保留当前存档用于恢复，不覆盖唯一存档。

1. **开关和收益**：检查基准内 Pawn 不变，超常社交 Pawn 在开启时收益递减，关闭后下一次结算恢复原公式。确认好感开关的两条路径及原版思想抵消／无心情通道仍正常。
2. **旧高额记忆**：使用已有高额关系记忆，或先关闭压缩让同搭档产生该记忆；开启压缩本身不改旧值，再次完成同搭档亲吻后，检查当前倍率／时长／旁白和一个关系槽。关闭压缩再吻，确认不是继续沿用压缩值。
3. **变体与隔离**：切换好感效果后再次吻同搭档，检查不残留旧变体／重复槽；其他搭档及墙／树不被定向清理，现有原版堆叠约束照常。不能获得思想时，不应因候选被拒绝而先删旧记忆。
4. **界面与存读档**：两种语言下控件与提示可读、不遮挡，开关关闭后重开／重载仍关闭，恢复默认后开启。保存／重载旧记忆应保留原值；刷新后保存／重载应保留新值及旁白。
