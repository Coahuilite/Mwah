# 更新日志

Mwah! 的公开版本记录。维护规则：

- 已发布条目按时间顺序，旧的在前；未发布条目置顶。
- 标题用本地发布时间 `[YYYY-MM-DD HH:MM UTC+8] 版本 X.Y.Z`；发布时替换 `未发布 — 版本 X.Y.Z`。
- 「首次上传创意工坊」的措辞只用于工坊第一次上传。
- 一条一个变化，写给玩家看；玩家没感觉的技术修复一笔带过。
- 英文版同步维护在 `docs/CHANGELOG.md`。

## 未发布 — 版本 0.2.2

第一个公开版本。0.1.x 开发线整条作废、从未发布，所以这一版把全部内容一次端上来。

先把丑话说在前面：这是个玩笑模组，只在游戏内地图生效，只支持单机，不用 Harmony，除 Core 外没有任何依赖。

### 新增

- 右键亲吻。选中一个小人，右键另一个。能走的那个走过去，两人面对面亲一个，爱心飘起来，完事各回原位。
- 亲吻导演台。底栏多一个按钮，开一个小面板：点地图上任意两个单位，把它们发配去亲。袭击者、商人、野生动物——你指挥不了的也能被安排。
- 亲墙。右键一面墙、一块岩石、甚至埋在地下的矿脉，凑上去亲。墙不会回应，心情全看运气：五档结果、五十句旁白，都在可改的 XML 里。
- 动物、机械族、异象实体都能亲。它们没有心情系统，不赚不亏，但各自有一套专属的吐槽：机械族讲冷笑话，动物只谈气味。
- 停火窗口。被安排去亲吻的两位，在亲完之前不会动手；挨一发子弹立刻破功。
- 心情按被亲的人头算。加成乘的是接收者自己的社交影响：会来事的赚得多，闷葫芦缩水，精神变态毫无感觉。
- 门禁滑条。"谁能亲谁"七档可选，从只限自家殖民者一路放到万物互亲，默认全开。
- 自主亲吻（默认关）。打开后，游戏自己撮合你管不着的单位，间隔和距离都由你定。它永远不碰你的殖民者。
- 设置页分四段：核心、自主撮合、附加功能、系统。所有时长都同时给出 tick、现实秒、游戏小时三种读法。
- 诊断分四档。平时安静，出问题时日志里有据可查。
