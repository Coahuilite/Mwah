# 更新日志

Mwah!（Every Pawn Kisses Each Other，中文名「所有Pawn都给我啵嘴！」）的简体中文标准更新日志。

规则：
- 已发布条目按时间顺序记录，旧在前、新在后；未发布条目置顶。
- 标题使用本地发布时间：`[YYYY-MM-DD HH:MM UTC+8] 版本 X.Y.Z`；发布时替换 `未发布 — X.Y.Z`。
- `创意工坊首次上传` 仅用于 Steam 创意工坊第一次上传。
- 每条 bullet 只写一个改动，面向玩家措辞；bugfix 简要带过，除非玩家可感行为变了。
- 英文版同步维护在 `docs/CHANGELOG.md`。

## 未发布 — 版本 0.2.1

首个公开版本。0.1.x 开发线从未发布即归档（2026-10-05 维护者裁定），以下全部内容随本版本一次登场。Mwah! 是一个有严肃边界的玩笑模组：仅游戏内地图、仅单机、零 Harmony、除 Core 外无任何依赖。

### 新增
- **右键点一个吻。** 选中任何可下令的 Pawn，右键另一个 Pawn：能走的那个走过去，两人侧向面对面站定，原版滚床单的爱心飘起来，完事各自回原位。选中的那个走不动？那就对方过来。
- **亲吻导演台。** 底栏按钮打开一个非模态面板——开着它地图照常框选、平移、缩放。左/右头像框走原版点选，可指定地图上任意两个 Pawn（包括你指挥不了的）；选一边心形红一半。快速发配两段地图点选直接派发。
- **亲一堵墙。** 右键人造墙、天然岩壁或被埋藏的矿脉，凑上去亲。结果由可编辑、XML 出厂的天意表掷出（五档，心情 −2 到 +6，50 条旁白），落成**唯一一条**"与墙的关系"记忆——下一次亲吻就地顶替（换档、换旁白、重计时）。附加功能是注册表：未来的树、工作台、机器各带各的开关、天意表与时长。
- **实体、动物与机械族也都能亲。** 没有心情系统的参与者照有动画、爱心和属于自己消息通道的天意短讯（机械族冷笑话、动物嗅觉叙事、实体空壳心理）——但不加心情，因为它们根本没有心情需求。蹒跚怪/食尸鬼/苏醒的死尸可被亲也可当发起方，准入与任何人类一样交给门禁滑条。
- **停火窗口。** 被下令的亲吻在整个 job 期间让双方都免战——接近、表演、回程全程——因为原版 job 归属天然压住 think tree。任意暴力命中立刻破功并反击；成对冷却与单人冷却限制玩法。系统绝不会把交火中的单位拽去亲嘴；你会。
- **自主撮合（默认关）。** 游戏按你设的间隔与半径，替你管不着的 Pawn（访客、商人、袭击者、野生动物、机械族）自己配对亲吻。它一次都不碰你的殖民者。
- **心情按被亲的人头算。** +5 基础 × 接收者自己的 `SocialImpact` × 设置倍率：社交达人亲一次更赚，哑巴收益缩水。精神变态毫无感觉（原版归零名单）。可选设置额外写入对彼此的看法（"我们的那一吻"），默认不碰原版恋爱链。
- **门禁滑条。** "谁能亲谁"七档累积，从只限自由殖民者到万物互亲（出厂最右）。灰项永远写明真实原因；唯一会静默消失的是被关掉的附加功能——关掉即从一切可选面消失，零提示。
- **设置页四段式。** 核心 / 自主撮合 / 附加功能 / 系统，顶部常驻标题区（副标题 + 构建水印，滚到哪截图都带着）。所有时长滑条带精确 tick 数值框，同时显示 tick / 现实秒 / 游戏小时。
- **诊断四档。** 关闭 / 自动 / 简化 / 详细。自动跟随构建渠道（dev 包=详细，发行包=简化：每桩结算吻一行天意落点 + 一切异常出口）。启动横幅与报错行永远播报。

### 打包
- dev 预演是整目录拷进 `Mods/` 的文件夹（默认不产 zip）；GitHub 发布 zip 可复现（唯一顶层目录、条目统一盖 commit 日期）。
- 中英双语键集合由 27 道离线门核对，含天意表完整性、零 Harmony 反证与推送前全历史隐私审计。
