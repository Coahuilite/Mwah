# 更新日志

本文件记录 Mwah!（Every Pawn Kisses Each Other）每个版本的显著变更，简体中文标准版；格式遵循 [Keep a Changelog 1.1.0](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## 更新日志规则

结构与分类：
- 已发布条目按时间顺序记录，旧在前、新在后；未发布条目置顶。
- 标题使用本地发布时间：`[YYYY-MM-DD HH:MM UTC+8] 版本 X.Y.Z`；未发布条目用 `未发布 — X.Y.Z`，发布时替换为实际时间。
- 小节使用 Keep a Changelog 标准类型：**新增**（新能力）、**变更**（既有行为改变）、**修复**（缺陷解决）、**废弃**（将来会移除）、**移除**（已删除）、**安全**（漏洞处理）；本项目另允许 **打包**、**说明** 两节。空小节不保留。
- 破坏性变更（存档兼容、设置迁移、既有行为不兼容改变）永远置顶单独成节，必须写清影响与玩家需要做的动作。
- `创意工坊首次上传` 仅用于第一次工坊上传；后续更新使用普通版本条目。

条目写法：
- 一条 = 一个显著变更，写**用户因此能做什么 / 什么问题没了**，不写实现与操作步骤；机制细节归 README，条目最多留一句指针。
- 以动词开头、现在时、单行为主；宁可两句短话，不要一句长说明书。
- 具体，拒绝"若干修复与优化"这类空话；没有显著变更的版本也要有条目，但只写真实发生的那几条。
- 用词准确、描述行为；戏谑与俏皮属于游戏内文案，不进更新日志。
- 不记录未接受的计划；已接受未发布的版本写进置顶的"未发布"条目。
- 只有同时影响 GitHub 与 Steam 发布面时才同时提及二者。

维护：
- 英文版同步维护在 `docs/CHANGELOG.md`，两种语言逐条对齐。

推荐条目格式：

```text
## [YYYY-MM-DD HH:MM UTC+8] 版本 X.Y.Z

一句话概述本次发布。

### 新增
- ...

### 变更
- ...

### 修复
- ...

### 打包
- ...
```

## 未发布 — 0.2.2

首个公开版本：任何 Pawn 亲任何 Pawn。玩法与机制细节见 README。

### 新增
- 右键即可让一个 Pawn 亲吻另一个，包括你无法下令的对象。
- 亲吻导演台：底栏面板，指定地图上任意两个 Pawn 发起亲吻，含两段点选的快速发配。
- 亲墙：人造墙、天然岩壁、被埋藏的矿脉都能亲；心情结果由可编辑的天意表随机决定。
- 动物、机械族、异象实体可被亲也能当发起方；它们没有心情变化，只收到各自通道的天意短讯。
- 被下令亲吻的双方在整个亲吻期间互不攻击；有效伤害立即中断。
- 心情加成按被亲方自身的社交影响缩放；原版归零名单上的特质使其完全无效。
- "谁能亲谁"七档门禁滑条，默认不限阵营、不限种族。
- 自主亲吻：游戏按你设定的间隔与半径，为你无法下令的 Pawn 自动配对；绝不代管玩家可控单位。
- 四段式设置页（核心 / 自主撮合 / 附加功能 / 系统）；所有时长同时给出 tick、现实秒、游戏小时。
- 四档诊断日志，默认跟随构建渠道；启动横幅与报错不受档位限制。

### 打包
- 包内随附 version.txt 身份标（版本、构建渠道、commit）。
- GitHub 发布 zip 可复现（唯一顶层目录、条目统一盖 commit 日期）。
- 中英双语键集合由全套离线门核对，推送前跑全历史隐私审计。
