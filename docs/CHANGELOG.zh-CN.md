# 更新日志

## 更新日志模板

本文件是 Mwah!（Every Pawn Kisses Each Other）的简体中文标准更新日志。

规则：
- 已发布条目按时间顺序记录，旧版本在前，新版本在后；未发布条目置顶。
- 标题使用本地发布时间：`[YYYY-MM-DD HH:MM UTC+8] 版本 X.Y.Z`。
- 顶端未发布条目可使用 `未发布 — X.Y.Z`；发布时替换为实际 UTC+8 时间。
- `创意工坊首次上传` 仅用于 Steam 创意工坊第一次上传；后续更新使用普通版本条目。
- 每条改动保持简短清楚，一条 bullet 只写一个改动。
- 用词准确、描述行为；戏谑与俏皮属于游戏内文案，不进更新日志。
- 需要时分为新增、变更、修复、打包、说明等小节。
- Bugfix 简要带过；只有影响玩家行为时才展开说明。
- 只有同时影响 GitHub 和 Steam 发布面时，才同时提到二者。
- 不记录未接受的计划；已接受但尚未发布的版本可使用上述明确"未发布"条目。
- 英文版需同步维护在 `docs/CHANGELOG.md`。

推荐条目格式：

```text
## [YYYY-MM-DD HH:MM UTC+8] 版本 X.Y.Z

一句话概述本次发布。

### 新增
- ...

### 变更
- ...

### 修复
- ...

### 打包
- ...
```

## 未发布 — 0.2.2

首个公开版本：游戏内地图上任何 Pawn 亲任何 Pawn——仅单机、零 Harmony、仅依赖 Core。

### 新增
- 新增右键亲吻：选中一个 Pawn，右键另一个 Pawn，由能行动的一方走到对方面前完成亲吻，双方头顶飘出爱心，随后各自返回原位。
- 新增亲吻导演台：底栏面板，可指定地图上任意两个 Pawn（包括玩家无法下令的）发起亲吻，另有两段点选的快速发配。
- 新增亲墙：人造墙、天然岩壁与被埋藏的矿脉均可作为亲吻目标；结果由可编辑的 XML 天意表随机决定（五档心情、五十条旁白），写入唯一一条"与墙的关系"心情记忆，下一次亲吻将其顶替。
- 新增动物、机械族、异象实体为亲吻对象与发起方：此类 Pawn 没有心情系统，不产生心情变化，仅收到各自消息通道的一条天意短讯。
- 新增停火窗口：被下令亲吻的双方在亲吻结束前不会互相攻击；任意一方受到有效伤害时亲吻立即中断。
- 新增心情加成：数值按被亲吻方自身的社交影响缩放；位于原版归零名单的特质（如精神变态）使其完全无效。
- 新增"谁能亲谁"门禁滑条：七档递进，默认最右档（不限阵营、不限种族）。
- 新增自主亲吻（默认关）：按设定的间隔与半径，为玩家无法下令的 Pawn 自动配对亲吻；不会为玩家可控的 Pawn 发起。
- 新增设置页：分核心、自主撮合、附加功能、系统四段；所有时长同时显示 tick、现实秒、游戏小时。
- 新增诊断档位：关闭/自动/简化/详细四档，默认跟随构建渠道；启动横幅与报错不受档位限制。

### 打包
- 包内随附 version.txt 身份标（版本、构建渠道、commit）。
- GitHub 发布 zip 可复现（唯一顶层目录、条目统一盖 commit 日期）。
- 中英双语键集合由全套离线门核对，推送前跑全历史隐私审计。

- 0.1.x 开发线未发布即归档，0.2.0 与 0.2.1 从未打 tag；以上全部内容随 0.2.2 一次登场，这就是首个公开版本。
