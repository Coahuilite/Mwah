## [2026-11-17 00:57 UTC+8] 版本 0.4.0

### 变更

### 打包

- 仅在 VNPE 启用时加载其登记及专用文案，本地美术原稿和文档归档不进入运行包。

## [2026-10-30 02:16 UTC+8] 版本 0.3.0

### 新增
- 亲树在没有文化 DLC 时仍可获得基础结果，可选按各 Pawn 文化及自己的 Gauranlen 连接选择结果。
- 为 RimWorld 1.7.4990 rev1069 构建原生 .NET 10 包，同时保留 1.6。

### 调整
- 更新封面，展示 1.6／1.7、配对亲吻、墙和树。
- 双人吻对超过 137% 的社交影响进行有界压缩，趋近 150%；默认开启，可关闭恢复原公式。已开启的好感变化共用压缩，墙／树不受影响。
- 同搭档再次亲吻时更新旧配对记忆的强度、时长及旁白，不只续期旧倍率；旧纯心情／好感变体收敛到同一搭档槽。
- 新双页设置优先管理扩展，隐藏或关闭前提交有效数值编辑。

### 修复
- 让仍可爬行的倒地接收方原地被动亲吻，不因本次亲吻预订被误中断；双方任一方失去参与资格时取消未完成的吻。
- 无双人台位时失能接收方仍在自身格等待，移动方贴近；手动导演台允许失能第一槽的移动回退，并报告实际角色。
- 表演结束即结束亲吻占用和报告，释放双方工作预订；合法新命令可接替返程，旧返程不抢回工作或重复结算。
- 配对表演等待双方匹配且到位，派发反馈按真实工作入场结果。
- 正常回程保留在亲吻工作内，不抢新命令；保存活动身份及结算状态。
- 冷却豁免统一应用，不绕过可达性或跨目标占用。

### 打包
- 隔离 1.6／1.7 程序集，从同一内容源生成两版本，并拒绝缺件或混装。
- 不屏蔽警告地修复原生编译告警，保留默认 1.6 构建入口。

### 说明
- 维护者确认 1.6／1.7 亲吻正常并接受 0.3.0 验收；1.7 原生适配目标为 4990 rev1069，同时保留 1.6。

## [2026-10-06 00:00 UTC+8] 版本 0.2.2

首个公开版本：任何 Pawn 亲任何 Pawn。玩法与机制细节见 README。

### 新增
- 右键即可让一个 Pawn 亲吻另一个，包括你无法下令的对象。
- 亲吻导演台：底栏面板，指定地图上任意两个 Pawn 发起亲吻，含两段点选的快速发配。
- 亲墙：人造墙、天然岩壁、被埋藏的矿脉都能亲；心情结果由可编辑的天意表随机决定。
- 动物、机械族、异象实体可被亲也能当发起方；它们没有心情变化，只收到各自通道的天意短讯。
- 被下令亲吻的双方在整个亲吻期间互不攻击；有效伤害立即中断。
- 心情加成按被亲方自身的社交影响缩放；原版归零名单上的特质使其完全无效。
- "谁能亲谁"七档门禁滑条，默认不限阵营、不限种族。
- 自主亲吻：游戏按你设定的间隔与半径，为你无法下令的 Pawn 自动配对；绝不代管玩家可控单位。
- 四段式设置页（核心 / 自主撮合 / 附加功能 / 系统）；所有时长同时给出 tick、现实秒、游戏小时。
- 四档诊断日志，默认跟随构建渠道；启动横幅与报错不受档位限制。

### 打包
- 包内随附 version.txt 身份标（版本、构建渠道、commit）。
- GitHub 发布 zip 可复现（唯一顶层目录、条目统一盖 commit 日期）。
- 中英双语键集合由全套离线门核对，推送前跑全历史隐私审计。
