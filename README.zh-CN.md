# 所有Pawn都给我啵嘴！ · Mwah!

[English](README.md) | **简体中文**

选中一个 Pawn，右键另一个，下令亲吻：能走的一方走过去，双方面对面，飘起原版爱心。**亲吻导演台**还能指定平时无法下令的 Pawn，或让 Pawn 亲墙、树和机器。

支持 **RimWorld 1.6／1.7**，仅游戏内地图、仅单机。只需 Core，不强制 DLC、框架或 Harmony。本文包含**尚未发布的 0.4.0** 机器吻与 VNPE 功能；已发布变更见[更新日志](docs/CHANGELOG.zh-CN.md)。

## 安装与更新

将完整打包后的 `Mwah` 文件夹放入 `RimWorld/Mods/`，只启用一份 `coahuilite.mwah`。不要把源码工作目录当安装包，也不要混用不同构建的 DLL。

更新时**完整替换旧模组文件夹，不叠加覆盖**；保留原存档和设置。包内共同内容位于根目录，每个游戏 minor 有自己的原生 DLL，可选兼容内容由 `LoadFolders.xml` 条件选择。

## 选择亲吻对象

- **Pawn 配对：**选中可下令的 Pawn 后右键搭档，或在导演台指定双方。清醒但不能移动的接收方留在原位，由可动方过去；导演台可选择非玩家控制的 Pawn，「快速发配」只需两次地图点选。
- **墙：**墙、天然岩壁和矿脉使用亲墙天意表，共用一个墙记忆槽。
- **树：**树木及其他模组标记为树的植物共用独立记忆槽。可选文化结果按亲吻者自己的信念及 Gauranlen 连接选择；没有 DLC 也能亲树，不改动修剪、连接或仪式。
- **机器：**工作台类型族、两种原版研究台、多元分析仪和营养膏机共用一个机器记忆槽。有电力组件的目标只需其 `PowerOn` 为真，不限制电从哪里来；非电力工作台不要求接电。
- **研究设备：**正面心情乘以 `1 + 识智/20`，识智封顶 20，不增加研究进度。
- **法式深吻营养膏设备：**好天意结果填满已有的饥饿需求，不要求原料、不消耗食物、不触发进食副作用。原版营养膏机与受支持的 VNPE 出口使用同一种特殊亲吻。

工作台与研究台使用工作／椅子交互格，不要求实际摆椅子。营养膏机优先领取格，也允许左右各偏移一格；多元分析仪只需合法接触位。无法抵达要求的站位时不能亲吻。

### 可选 Vanilla Nutrient Paste Expanded 兼容

启用 VNPE 后，**排出口、供给器、滴喂器**均可接受法式深吻。排出口使用领取格或左右相邻格；后两者使用可达、可站立、可预订且满足原版 Touch 的位置。只要求供电，不要求管网存量或床位连接，也不消耗资源。

三个目标的登记及专用文案仅在 VNPE 启用时加载；缺少该模组不影响其他功能。这份兼容不修改 VNPE 的生产与喂食规则。

## 奖励与中断

配对亲吻的心情奖励按参与者**自己**的有效 SocialImpact 和设置倍率缩放；无心情者仍可参与，并走适用的旁白／短讯通道，不发心情奖励。重复配对亲吻刷新对应搭档的记忆；墙、树、机器各替换自己的单个记忆槽。

未完成或被中断的亲吻不发完成奖励，伤害可打断 Job。表演结束就已完成亲吻：返程释放亲吻占用，不再次结算；合格的新命令可接替返程，但仍检查冷却。

## 设置

**玩法与扩展**提供扩展开关、各扩展记忆时长、亲树文化选项、配对范围、导演台和自主亲吻。**参数与杂项**提供时长、冷却、配对收益、诊断和恢复默认值。关闭功能会保留其偏好。

时长同时显示 tick、现实秒和游戏小时，以 tick 存储。数值编辑在回车、失焦、切页或关闭时提交。配对范围只限制 Pawn 配对，不限制墙／树／机器。

自主亲吻**默认关闭**，只撮合 Pawn 配对，不选择玩家管理的发起方或正在征召的玩家接收方。超常 SocialImpact 压缩默认开启：137% 以内不变，超出部分收益递减并趋近 150%；仅影响配对心情及已开启的好感收益，不影响扩展奖励。

## 构建与贡献

完整双版本构建需要 .NET 10 SDK 和可用的 NuGet 还原／缓存；构建不会安装到游戏目录：

```powershell
pwsh scripts/verify-local.ps1
pwsh scripts/pack-dev.ps1 -Zip
```

安装包文件夹为 `dist/dev/Mwah`。[贡献指南](CONTRIBUTING.md)说明源码布局、兼容约束和允许的检查；[文档目录](docs/README.md)提供架构、诊断、规格和发布指引。实机测试由维护者执行。
